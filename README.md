# 📋 Telegram TODO & Shopping List Bot

Умный Telegram-бот на **Node.js / TypeScript (grammY)** с сохранением в **SQLite**, который читает сообщения пользователя и автоматически формирует интерактивные списки покупок и задач.

## ✨ Ключевые возможности

1. **Гибридный парсинг сообщений:**
   - **Умный локальный парсер (мгновенно, без задержек и без внешних API):**
     - Распознает списки через запятую: `молоко, хлеб, сыр, яйца`
     - Распознает списки с новой строки (маркеры `-`, `*`, `•`, нумерация `1.`, `2)`)
     - Распознает союзы: `купить хлеб и молоко`
     - Автоматически сортирует пункты по категориям: продукты и товары отправляются в **🛒 Покупки**, а действия и звонки — в **📝 Дела**
     - Поддерживает явные префиксы: `Покупки: ...` или `Дела: ...`
   - **Интеллектуальный AI-парсер текста и голосовых сообщений (Google Gemini):**
     - **Свободная речь в тексте:** понимает сложный разговорный текст любой длины и извлекает из него конкретные пункты (например: *"Завтра надо заехать на заправку и не забыть в магазине взять бананы и кефир"*).
     - **Голосовые сообщения:** просто отправьте голосовое сообщение в чат с ботом — Gemini расшифрует речь, выделит покупки и дела и сразу же добавит их в активный список.
     - Если ключ не указан, бот надежно работает на локальном парсере.

2. **Интерактивный интерфейс Telegram и жизненный цикл списка как сущности:**
   - Вкладки переключения между **🛒 Покупки** и **📝 Дела** в один клик.
   - Вычеркивание пунктов по нажатию (кнопки `⬜` ↔ `✅`).
   - Кнопка **📷 Сканировать товар** прямо в карточке покупок (поддерживает запуск камеры через Telegram WebApp или отправку фото в чат).
   - **Список как единая сущность и бесконечное дополнение:** активный список покупок и дел существует как непрерывная сущность (`todo_lists`). Любые входящие сообщения от пользователя или в группе автоматически дополняют текущий активный список и обновляют интерактивную карточку в чате на месте. Список дополняется до тех пор, пока пользователь не нажмет кнопку **«🏁 Закрыть список»** (или команду `/close`).
   - Кнопка **🏁 Закрыть список** фиксирует текущий список, подводит итоги и закрывает его. После закрытия следующее сообщение начинает новый чистый список.
   - Кнопка **🧹 Удалить выполненные**.
   - Кнопка **🗑 Очистить всё** с защитой от случайного удаления (подтверждение).
   - Кнопка **📋 Текстом** для быстрого копирования или пересылки списка родным/друзьям.

3. **📷 Автоматизация считывания штрихкодов и подсчет корзины:**
   - Сфотографируйте штрихкод товара или ценник на полке — Gemini Vision распознает товар, штрихкод и цену.
   - Если товар есть в списке покупок — бот отмечает его как купленный и сохраняет цену.
   - Если товара нет в списке — бот автоматически добавляет его в активный список покупок и отмечает купленным.
   - В карточке отображается сумма купленных товаров: `💰 В корзине: 450 ₽ (из 620 ₽)`.
   - Поддержка ввода штрихкода цифрами в чат, команды `/scan <код> [цена]`, а также нативной камеры смартфона через Telegram WebApp.

4. **Надежная база данных:**
   - Локальный SQLite на базе `@libsql/client` (быстрый, не требует компиляции Visual Studio C++ на Windows).
   - Модель данных с сущностями `todo_lists`, `items` и локальным каталогом товаров `products_catalog`.
   - Индивидуальные списки для каждого пользователя и группового чата.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлены [Node.js](https://nodejs.org/) (версии 18+) и npm.
В папке проекта выполните:
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
*(В Windows PowerShell: `Copy-Item .env.example .env`)*

Откройте `.env` и задайте параметры:
```env
# Токен бота из Telegram от @BotFather (ОБЯЗАТЕЛЬНО)
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ключ Gemini API для текста и голосовых сообщений (ОПЦИОНАЛЬНО)
# Получить бесплатно: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=

# Модель Gemini (по умолчанию gemini-2.5-flash)
GEMINI_MODEL=gemini-2.5-flash

# Файл базы данных SQLite
DB_PATH=file:todo_bot.db
```

#### Как получить `BOT_TOKEN`:
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите название и username бота (например, `MyShoppingTodoListBot`).
4. Скопируйте выданный API токен в переменную `BOT_TOKEN` в файле `.env`.

## 📱 Примеры использования

Просто отправьте боту сообщение в чат:

- **Голосовое сообщение:**
  Запишите голосовое: *«Купи сыр, масло и не забудь забрать посылку»*.
  Бот расшифрует речь и добавит пункты по нужным вкладкам с пометкой `(✨ AI)`.
- **Список через запятую:**
  ```text
  молоко 3.2%, бородинский хлеб, сыр гауда, яблоки 1кг
  ```
- **Маркированный или нумерованный список:**
  ```text
  1. Позвонить врачу
  2. Забрать заказ из пункта выдачи
  3. Оплатить интернет
  ```
- **Смешанный разговорный текст:**
  ```text
  Надо поменять масло в машине, а в супермаркете захватить чай и печенье
  ```

## ⌨️ Команды бота

- `/start` — Приветствие и показ текущего списка
- `/list` — Открыть интерактивную карточку со списком
- `/scan` — 📷 Сканировать штрихкод или ценник (`/scan 4600605021234 [цена]`)
- `/shopping` — Перейти в 🛒 Список покупок
- `/tasks` — Перейти в 📝 Список дел и задач
- `/close` — 🏁 Закрыть текущий список (следующее сообщение начнет новый список)
- `/clear` — Удалить вычеркнутые пункты из активного списка
- `/export` — Вывести списки текстом с галочками для копирования
- `/stats` — Показать статистику (всего / выполнено / осталось / сумма корзины)
- `/myid` — Показать свой Telegram ID
- `/help` — Справка и примеры сообщений

```
│   ├── config.ts       # Загрузка и валидация конфигурации (.env)

├── test/

│   ├── test-db.ts      # Автотесты жизненного цикла списков, цен и БД

├── .env.example        # Пример конфигурации
├── package.json
└── tsconfig.json
```
